无可否认的是，双非这个身份在找工作和保研方面都极具劣势，就好比王者打团输了，那你的经济必然比对面落后，那么下一个团要能够赢过别人，就只能在勤奋和策略中付出比别人更多，才有取胜的希望。但是更多时候其实连下次打团的资格都没有了，即简历关都过不了（eg: 某里，某手，某影，某石，某站（我的白月光(ಥ_ಥ)）等等，当然多尝试尝试说不定你还是有机会的），当然好在还是有一些所熟知的大厂还是有机会的，但是回过头来看更多的是运气到了的时候，我当时的能力恰好满足了吧（感谢企鹅收留我，我是忠实的鹅孝子）。如果不是舍友斗胆投了腾讯的暑期，我或许都不敢去投递。如果不是面试官使用私人电话打过来的，我就错过了暑期的面试。如果不是机缘巧合在大一下的时候有一个很好的 ai 社群（虽说是一家小公司所创建的交流群），让我在 23 年底的时候就开始接触 ai，也就不会刚好碰到 26 年初 agent 爆发的那段时间我可以在面试中滔滔不绝的和面试官聊 agent。如果不是暑期的业务刚刚好和我在入职之前就一直在捣鼓的东西有关，或许也没法做到答辩需要的产出。总之我不觉得我在计算机方面有多么多么厉害，毕竟准确来说我只是自学了 2 年半的小卡拉咪罢了，甚至一开始的专业还不是计算机而是化学（没错，甚至我的分数还不支持让我读现在学校的计算机专业，于是花了半年转专业，并且是真正的从零开始，那时候连 steam 怎么装都不知道），所以更多的是时也运也，毕竟我的秋招也极其惨淡，除了腾讯的转正，一共也就 2 家公司 6 场面试，一个字节一面挂，二面挂，小米三面面完泡池子了。（当然投递的基本上都是在互联网上默认的中大厂，因为手上有一个转正保底，所以策略就改变了，如果秋招你手上没有保底 offer 的，请疯狂海投，多试试总不会错的～）

有感而发的说了这么多，接下来就进入正题吧，其实每个点都或多或少对应着上面的一些内容，如果能稍微帮助到你那将是无比荣幸。

# 一、保持适当的锻炼
对的，在最开始，我不想说如何学习，我想先强调一点，适当的锻炼不仅可以健康的释放压力，而且还可以让你更能卷。虽然说这个说起来很简单，但是在压力之下坚持下来却是有点困难的，毕竟谁不想累了一天了，瘫床上刷有意思的小手机呢。从前我并没有意识到这个事情，直到某天我刷到了一个帖子，贴主说他即使秋招那段时间特别难熬，但是还是坚持不间断的锻炼来释放压力，那时候我才意识到高三下那年我打破了之前的作息，简单的认为空闲时间和朋友们的锻炼是浪费时间的，放弃了 2 年半来锻炼给我带来上瘾的正反馈，不如全部投到学习上面，（经常14 点在座位上埋头狂写，抬头就是 22 点晚自习下课了），或许这种对于短期的突击是有效的，但是对于长达几个月甚至一年的目标来说就显得有点滑稽了，毕竟高度紧绷的神经除了持续压力你自己以外没有任何的好处，而恰好锻炼是一个很好的释放压力的方式，毕竟，借用徒步圈的一句话，大致意思是，"当你朝着山顶攀登的时候，脑子里就不会有其他杂念了"，所以在那之后我也在不断努力践行着这种理念，虽然说有时候还是会懒癌发作，但是好在也有保持适当的锻炼了。所以如果你最近心烦意乱，不如去跑个步吧～

# 二、你真正喜欢什么
again，我还想先问一下，你真正喜欢什么，我主观的认为，在当下 agent 飞速发展的时代，只有真正找到自己喜欢的东西才能有所谓动力支撑着你不断的走下去，这也是我曾经的+2 告诉我的:"追求出人头地，现在投入和收入已经不那么吸引人了，已经没有经济上升时期那么大了，利用现在的生产力，做自己喜欢做的事情，过充实的人生，反而过的更划算一点"。所以读了 18 年数的我也一直在寻找我真正喜欢什么。承然计算机互联网的整体薪资十分诱人，但是代价也十分明显，需要你不断的持续学习、不可避免的加班等等弊端，那当一个变化突然降临（诸如 ai 大人）的时候，如果没有你真正喜欢的事情可以支撑的时候，这时候或许就会走向消极的一方面，进而一蹶不振。相反的，如果你真正喜欢某件事情，你也会借助 agent 这个生成力来去进一步丰富自己，毕竟凡事都是一把双刃剑，取决于当下的你如何看待了。

>所以若你迷茫，不如找找自己真正喜欢什么吧～

# 三、一个转专业人的就业时间线 & 一些碎碎念
前面提到的零基础并没有任何的夸大，在转专业过来之前我对电脑的认识就只停留在 4399 这种水平上，所以一开始的时候更多的是补基础跟着网课和学校的课程在学 c/java，承让我当时是有报培训班的，其中的路线在前 agent 时代（25/26 年之前）对我的学习路线起到了引入人的作用，然而在 ai 时代，我不推荐你报任何的培训班，因为在 agent 时代，知识的获取已经变得相当简单了，但是无可厚非培训班让我尽早的看清了局面，笨鸟先飞了（现在你想要获取这些知识，只需要你有意识的去接触就业的相关信息，那么就可以很方便的获取到了）。然而学校的课程我就转专业后的大一下学期老老实实的上了，后面发现确实和网上所说，跟着学校上课毕业即失业，对于互联网行业来说没有任何夸张成分，尤其在 agent 时代，还守着你零几年的教材呢，并且绝大多数老师还秉持着不学好我的课你拿什么找工作的思想，甚者还有吧 python 写成 pathon 的...(当然还是有很让我尊敬的，真正在好好教有用知识的老师)，所以经历一个学期之后我就开始了自学之路。

大一至大二期间，我更多的精力放在保研所需要的事情上，绩点，比赛，学生工作等，那时候的想法便是读个好的研究生，刷一下学历。但是愈发了解之后，对学术愈加祛魅，很大程度上也是利益团体的组合罢了，并且你的导师也未必比你懂多少，更何况近年来的学术事件就不必多说了。承然我也见过真正做研究的老师/导师，无比向往，但是一想到要去花极其多的时间去刷无意义的绩点和 ppt 大赛（挑战杯/互联网+等）便渐渐降低了保研的权重（无意义仅个人感受），转而去走就业的方向了。（之所以是降低，是因为就业方向当时没有任何把握，所以并不敢完全 all in，毕竟总是要给自己留一点后路的，虽然说当时保研也不是十拿九稳，所以总得来说有赌的风险）

于是在 24 年的时候（大二上），那时候的 agent 远不如现在这般强大，连力扣 hard 都无法一把过，更多时候是一个大号的搜索引擎，所以那段时间还是按部就班的跟着网课进行古法编程，事后看来还是非常感谢经历过古法编程，一方面是我真正从手搓代码中体会到了乐趣，一个形象的比喻大概是数学卷子最后一道大题完美拿下的那种无与伦比的正反馈，可惜这种心流的状态在 vibe-coding 时代很少体会到了，只剩下最后成品交付的那种喜悦了。另一方面是初步掌握了或者说理解了好的架构应该是怎么样的，对于一个工程来说如何通过合理的架构来进行书写代码的能力在 agent 时代显得尤为重要，毕竟当大多数细节都交给 agent 之后，架构方面还是需要开发者来进行把关的，总不能乱拉屎吧。

>所以不要过度依赖 agent，请务必打好最基本的基础代码能力，然后在借助 agent 来进行进一步的学习和能力放大（关于 agent 方面的部分还会在后续章节展开）

 大二上寒假的时候我的进度基本上就是把 java 后端所需要的基本内容学完了（ javase，springboot，redis，mq，mysql）并且写了2 个项目，但是当时犯了一个很大的错误，觉得自己什么都会了，可笑的是那时候的我可以说只是跟着教程走了一遍，连底层原理和八股都没有开始准备，就觉得自己真是天才，以至于大二下学期我开始了摆烂模式，甚至连实习投递的时间都没有记清楚，直到大二下6 月份底要结束的时候才开始投递实习的简历，不出意外，那时候经历过暑期实习/日常实习的投递高峰，已经没有什么实习岗位了。以至于这样投递到了八月份才有一个客户端的实习机会。（是的，当时连客户端都不知道是什么就去了）但是其实 9 月份的时候还是有面试机会的，因为 9 月初，暑期实习的实习生都陆陆续续离职了，所以这段时间对于日常实习来说还是有一些机会的，可惜当时并没有很清楚的搞明白时间线，导致 8 月份实习过程中并没有复习相关的知识点，以至于某书的面试在分布式和高并发场景题下面被拷打的体无完肤。

>所以”读的越多读的越少“，任何时候都戒骄戒躁，当你了解的越多才会发现自己了解的越少，保持一颗谦卑的心个人感觉是很重要的，既不会招人厌，也可以更好的鞭策自己。

>对于后端的学习路线不过多说明，b 站也有很多的免费高质量路线，同时不要局限于网课，有一些经典书籍还是需要阅读的，具体的可以参考文章开头那篇帖子里面学长提到的书，以及借助互联网查看你所对于的领域里面的经典书籍（毕竟后端也是一个很大的统称）。客户端部分对于在校生主要就是四大组件，UI 体系（UI 绘制流程，自定义 view，事件分发），应用框架（Binder，一些重要系统类之间的交互关系）等，但是其实目前就业市场（2026 年），对于实习生来说你拿后端简历也是可以投客户端的（不过客户端属于鄙视链底层就是了，当然可能 27 年之后就是全栈了，所以不要局限于某个岗位，借助 ai 不断的以现有的知识举一反三，拓展自己的广度和深度）。不过更好的是去 github 上面找一个你感兴趣的项目拉下来借助 agent 学习才是最高效的～

## 实习过程
时间线如下:

2025.8-11 第一段实习

2026.1-2026.4 第二段实习

2026.4-2026.9 第三段实习（9 月答辩转正）

2026.9-2026.10 秋招投递

总的来说除了第一段时间稍微有点晚了，其他的时间倒是刚刚好（当然这也是这一两年的时间线，当越来越多人意识到实习的重要性之后，说不定就会更加提前了吧，总之多关注前一届的时间线进行参考即可，毕竟互联网时代，你想要获取这种信息还是非常简单的）。

>目前行情下的相关就业时间线：大二下 4-6 月份就可以开始投递第一段实习了，争取大二暑期开始实习，看个人情况大三上当前所在的公司是否有继续实习的必要，如果没有就尽量在 9 月初投递开始一段新的实习，然后就是明年大三下寒假过完之后 2-3 月份 - 5 月份开始的暑期实习，最后秋招的时间大概从 8 月底就陆陆续续开始了。


可能注意到第一段和第二段中间空了2 个月，一方面是期末考原因，另一方面是当时没有把握就业这条路线能够拿到我想要的结果，所以还是会分配一点精力到保研上，于是那段时间又抽空跟着学长写了篇论文（当然是做 dirty work 了）以及打了个比赛（被朋友带飞的，也是做 dirty work，所以尽可能的结交一些厉害的朋友总是没错的，需要打杂的时候就可以出出力了）。

最后在 9 月初的时候答辩和本校保研结果确定刚刚好在同一天，很幸运的两者都拿到的结果，最后还是选择了就业，一方面是我能在这过程中找到我的乐趣，也拿到了我满意的结果，另一方面我觉得我没有天赋去做类似 ai infra，也不想花三年去刷个文凭最后出来还是做现在的工作，同时也觉得 agent 的能力继续提高会摧毁当前的教育体系和评价体系，并不想当小白鼠，并且在研究生扩招的情况下，三年后的就业竞争压力未必会比现在的小。当然以上仅是我的主观选择，请谨慎看待。

> 总的来说，是否给自己留一点退路取决于个人，如果有精力有机会，那么留点退路总归是好的，

在校招前实习过程中，获取技术知识远比实习所给的钱来的重要，毕竟对于双非来说，titile 还是很重要的。对于转正实习和非转正实习，（即暑期实习和日常实习）在实习上有些许不同。


非暑期实习主要的目的大致如下：

1. 加深你对该领域的工程理解，看看企业级的代码都是如何进行组织协作，发版，版本管理的，在安排给你的任务里面尽可能的去体会代码协作，提升你对该领域的理解和实践能力。

2. 认识前辈，尝试进行社交，帮助你了解相关领域的知识以及获取一些前人的建议（并非全是正确的，但是总能有点收获）

3. 偷产出，即包装，只要你能看到的代码/文档，那都是你的，尽可能的转化为自己内在的知识，无论是对某一个线上问题的处理方式还是架构上的设计等等，都是可以进行借鉴和学习的，对于之后的真实业务场景或者面试的回答都是可以进行迁移运用的。
暑期实习如果是奔着转正去的，那么前面的第三点就不适用了，毕竟是要在组内进行答辩的。

4. 那么此时就要学会向上管理，做好 mentor/leader 给的任务仅仅是基础，更多的时候还是需要你能够做一些额外的事
情让别人记住你，即抛头露面，刷存在感。

5. 另一个就是卷，适当情况进行主动的加班表现一下或许有点帮助（当然这个点有点看组，如果大家都不加班那也没必要，如果有加班的“文化”，那么还是需要的）。

6. 谨慎对待画大饼行为，借网友的一句话："如果你不知道你能不能转正，那就是不能"，话糙理不糙，如果你的上级没有对你任何表示，那么谨慎 allin，该偷偷该投投。

关于卷这件事对于日常实习不是必须的，毕竟你并不要求当前公司给你提供什么就业岗位，只是一个跳板用来学习技术而言，达到目的即可。这就引出很重要的一点了：在就业过程中，永远把自己的利益放在第一位，不要投入过多的感情到公司里！！！！

这个道理或许是我实习一年以来学到最有价值的道理，以前可能觉得做人不能这么无情之类的，但是其实就业者才是弱势群体，你所在意的情感在公司的业务收益面前可能不值得一提。
你需要实习机会/就业岗位...，公司需要你创造业务收益/维护业务...，大家只是各取所需罢了，如果投入过多的感情，或许到最后被抛弃的时候发现一点退路都没有，极其狼狈。前辈的教诲如此，身边人的案例如此。

## 实习过程中家里人的反对
这边进行个插曲说明，在我实习的时候遇到家里人的反对，或许我的经历可以给你一点解决思路。
如果你的长辈只是凭借着互联网上的短视频之类的告诉你要读研考公，并且此时你已经有清楚的计划的时候，我觉得可以适当的编造谎言来搪塞过去或者先斩后奏，遵从你自己的内心，毕竟大多数长辈还是守着学历论和考公稳定的那一套思想，或许在 10 年前，20 年前是对的，但是放到现在就未必了，研究生和公务员的蓄水池在不断变大，是否会变成《以日为鉴：衰退时代生存指南》这本书里的样子，我们也不可知，但也只能管中窥豹，遵守你当下内心觉的正确的选择，不留有遗憾，自己的人生应该由自己做主不是吗。"我们要做的事情，就是别让时代的悲剧，变成个人的悲剧"。
当然如果你的长辈是确实有门道/有资本给你进行托举的，那就请你自行评估，权衡利弊了。
毕竟地球 online 没有办法回档，与我而言，我更想去看看更大的世界，而不是过早的稳定，哪怕可能最后是错的。i just do what i love，追求你真正喜欢的东西吧～

## 学校课程处理的一些经验
回归正题，开始实习之后，就开始了与学校课程拉扯的过程了，大多数人也会碰到这种情况，我的建议是如果有正规的方式就走正规的。如果有灰色地带的方法，请务必打听清楚在进行行动，避免被导员关注。如果明确不放实习那就只能去校园墙上找靠谱的代课了，总之方法总比困难多，激灵一点，有时候该花的钱不能省，多找找学长学姐，总是有意想不到的收获的。
一些涉及到平时成绩的科目，可以和一些靠谱的想要保研的同学打好关系，请对方吃顿饭，买杯奶茶等，让对方帮你关注一下课程的动向和需要提交的作业，以及最重要的点名签到，确保不会因为实习导致挂科延毕，我相信既然你都选择就业了，那么考试的内容及格来说应该是不成问题的了，所以务必关注签到这个问题，毕竟总有讲不通道理的老师。
对于需要线下参加的期末考试等，可以查看你们学校的政策，是否有缓考等手段，把相对分散的时间进行集中起来，减少往返的时间成本的金钱成本。


# Agent 时代如何学习

学习分两个方面：一个是前沿 agent 知识的学习（并非 ai infra，偏向于 ai 实践技巧，agent 系统的应用层搭建）；一个是利用 agent 进行高效的学习对于领域的知识。
主要有以下一些渠道：

1. x 上的一些优质博主帖子分享

2. openai，anthropic，gemini 以及国内 DeepSeek等相关公司发布的博客、论文内容

3. 一些社群论坛，比如 linux.do，datawhale ，github 上项目 readme 里面的一些官方社群等

4. 国内外的课程教程，比如DeepLearning.AI，youtube上的视频，b 站的视频（往往来说等翻译中文到国内了，大概率已经落后了一段时间了，所以能科学上网就科学上网去看看外面的世界）

对于后者来说，没有什么固定的方式，或许一个强大聪明的 agent 即可，更多的是当你有一个无所不在，无所不能的老师之后，剩下的就是你不断的提问学习的过程了。当然对于一些传统的路线，比如前后端的基本知识掌握的路径，在有成熟的路线优先按照前人的路线来进行打基础，然后过程中沿着主干借助 agent 不断开枝散叶，拓展自己的知识树。

所以抛弃老旧的教科书吧，确保不挂科的前提下，不断的利用先进的生产力来不断丰富自己~

回过头来看当时的不断追逐 agent 热点的日子给了我很大的帮助，一方面是提高了我的生产力，可以非常快速的学习相关知识，进行查缺补漏，拓展深度。一方面是让我在面试官面前相比于其他竞争者有了亮点，因为那时候属于是爆炸的时候，你的面试官可能因为业务压力并不是很了解那些前沿的 agent 实践，那么在大家都不了解的情况下就相当于你抓住了这个风口来展示自己的机会。

## 博客记录
在学完一个东西之后如果有时间最好的方法是用自己的话吧改内容的知识点给他记录下来，博客的首要任务是让知识真正内化为你自己的思想，而不是仅仅跟着课程过了一遍，前后两者在长久记忆上的区别是不一样的。以网络相关知识为例，从客户端到服务端的交互这边入手，涉及到的知识点大概可以从交互方式来进行层层展开：

1. 过程中采用的网络通信是 http 还是 https

	1. http 和 https 的区别

		1. http 底层架构的演进是怎么样的，为什么这样演进，有什么好处

		2. tcp 和 udp 有什么区别

			1. tcp 做了什么来保证传输的可靠

				1. 除了三次握手和四次挥手，中间过程还有其他的措施来保证传输的稳定吗

			2. udp 适合什么场景使用

	2. https 是如何保证安全的

		1. tls 握手时，客户端和服务端各自做了什么

			1. 为什么不能直接用对称加密通信

			2. 为什么不能只用非对称加密通信

			3. 实际为什么是“非对称协商 + 对称传输”的混合方案

		2. 以最近的 emudhra 证书密钥这个 case 说明为什么会导致互联网的安全问题

		3. 对称加密和非对称加密有什么区别

			1. 为什么非对称加密更难破解，数学上的原理是什么

这样就可以帮助自己梳理相关的知识点同时写成博客还有一个好处就是可以让你和竞争者在面试的时候有些许锦上添花的亮点体现，毕竟要是认真维护自己的博客，面试官是一眼就可以看得出来这个面试者是有自主学习复盘的能力的
